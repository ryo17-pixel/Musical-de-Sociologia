# Musical de Sociologia

Uma experiência web editorial sobre as ideias que organizam a vida em sociedade. A página apresenta o tema como um espetáculo em três atos: estrutura, cultura e mudança.

## Recursos

- Layout responsivo para desktop e dispositivos móveis
- Navegação por atos e seções
- Trilha sonora com controles interativos de reprodução
- Identidade visual inspirada em cartazes teatrais
- HTML, CSS e JavaScript em um único arquivo

## Como executar

Não há dependências ou processo de build. Abra o arquivo `index.html` diretamente no navegador ou use um servidor local:

```bash
python3 -m http.server 8000
```

Depois, acesse <http://localhost:8000>.
